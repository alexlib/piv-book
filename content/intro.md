# Reading PIV

How particle image velocimetry really computes a velocity.

This book explains the principles of PIV processing, so that new users can
choose parameters and read results with understanding. Every chapter is a
[marimo](https://marimo.io) notebook: the figures are computed live, and the
controls re-run the analysis. All images are synthetic with a known true
displacement, so each step can be broken on purpose and the error measured.

## Chapters

1. **A PIV Run, Start to Finish**: a complete OpenPIV analysis as six
   decisions. The map for the rest of the book.
2. **The Correlation Peak**: why one shift per window is the measurement, and
   how it fails.

Planned: interrogation windows and resolution; peak finding and
peak-locking; multi-pass and window deformation; validation; derived
quantities; a parameter-choice checklist.
